Numerical Methods — Statistics · Experimental Design

2² Factorial Design

Two factors · two levels each (−1 / +1) · r replications · main effects and interaction

Replications & Observations
STEP 1 — Choose the number of replications r ?
Replications (r)
The number of times each treatment combination is run.

Total observations N = 4r. Error df = 4(r−1), so r ≥ 2 is required.
STEP 2 — Enter every observation ?
Observation table
Each row is one treatment combination:
(1): A low, B low   a: A high, B low
b: A low, B high   ab: A high, B high

Every cell must contain a number. Negative and decimal values are allowed.
Changing r keeps the values you already entered. New replication cells start empty.
STEP 3 — Choose significance level ?
Significance Level α
Reject H₀ when p < α.
The same α is used for A, B and AB.

CONTRASTS, SUMS OF SQUARES & EFFECTS
A = −T(1) + Ta − Tb + Tab   SSA = A² / 4r
B = −T(1) − Ta + Tb + Tab   SSB = B² / 4r
AB = T(1) − Ta − Tb + Tab   SSAB = AB² / 4r
Effect = contrast / 2r  (A, B and AB)
SST = Σy² − CF,   CF = G² / 4r
SSE = SST − SSA − SSB − SSAB
DEGREES OF FREEDOM & F-TESTS
df: A = 1, B = 1, AB = 1, Error = 4(r−1), Total = 4r−1
F = MS / MSE, with MSE as the common denominator
p-value = P(F ≥ Fobs) from the F-distribution
Reading the interaction:
If AB is significant, the effect of A depends on the level of B. Main effects should then be read together with the interaction plot.
Assumptions: independent observations; errors approximately normal with equal variance; the four treatment combinations were run in a randomised order.
