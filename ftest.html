Method Overview
F-test statistic
F = s₁² / s₂²
df₁ = n₁ − 1  (numerator)
df₂ = n₂ − 1  (denominator)
Hypotheses & decision rule
H₀: σ₁² = σ₂²
Two-tailed (≠): p = 2·min[P(F≤f), P(F≥f)]
  critical: F1−α/2 and Fα/2
Right-tailed (>): p = P(F ≥ f), critical Fα
Left-tailed (<): p = P(F ≤ f), critical F1−α
Reject H₀ if p ≤ α; otherwise fail to reject.
Fp(df₁, df₂) = value with area p to its right
Assumptions
  • Two independent random samples
  • Each population is normally distributed
  • Sample variances use the n − 1 divisor
  • Positive, finite variances; n ≥ 2 in each sample
Key insight
F is a ratio of variances, so it is never negative and is right-skewed. F ≈ 1 means similar spread. The F-test is sensitive to non-normality, so use it with care.
