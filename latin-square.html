Latin Square Design

Rows · columns · treatments · each treatment once per row and column · three separate F-tests

Latin Square Arrangement & Parameters
STEP 1 — Choose the order t ?
Order of the square
A t × t Latin square has t rows, t columns and t treatments.

Each treatment appears exactly once in every row and every column.

Order 2 is not allowed, because the error df = (t−1)(t−2) = 0.
STEP 2 — Enter the treatment and observation in every cell ?
Latin square table
Rows are row blocks, columns are column blocks.

Each cell has a treatment label (top, coloured) and an observation (bottom).

Every treatment must appear exactly once in each row and each column.
Row and column names are optional. Empty names become Row 1, Col 1… Every cell needs a treatment label and a number.
STEP 3 — Choose significance level ?
Significance Level α
The risk of rejecting H₀ when it is true.

Reject H₀ when p ≤ α.
Used separately for Rows, Columns and Treatments.
Method Overview
MODEL & PARTITION OF VARIATION
xijk = μ + ρi + γj + τk + εijk

SST = SSR + SSC + SSTr + SSE
SSR = Σ(Rᵢ² / t) − CF  (rows)
SSC = Σ(C₏² / t) − CF  (columns)
SSTr = Σ(Tₖ² / t) − CF  (treatments)
SSE = SST − SSR − SSC − SSTr
CF = G² / N    N = t²
DEGREES OF FREEDOM & F-TESTS
df: rows, columns, treatments = t−1  |  error = (t−1)(t−2)  |  total = t²−1
Rows: F = MSR / MSE
Columns: F = MSC / MSE
Treatments: F = MSTr / MSE
How the calculation works:
① Check that the arrangement is a valid Latin square
② Compute row, column and treatment totals and the grand total
③ Split SST into rows, columns, treatments and error
④ Divide by df to get mean squares, then compare each F with the F-distribution
KEY INSIGHT
All three F-tests share the same error term
The error df (t−1)(t−2) is positive only for t ≥ 3.
Assumptions: observations are independent; errors are approximately normal with equal variance; row, column and treatment effects are additive (no interaction term); the square was randomised correctly.
