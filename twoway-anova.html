Two-way ANOVA

Two-way classification without replication · Separate F-tests for Factor A and Factor B

Data Table & Parameters
STEP 1 — Enter observations: rows = Factor A, columns = Factor B ?
Two-way data table
Each row is a level of Factor A.
Each column is a level of Factor B.
Each cell holds one observation.

At least 2 rows and 2 columns are required. Every cell must be a number.
Row and column names are optional. Empty names are replaced with A1, A2… and B1, B2… Every cell must contain a number.
STEP 2 — Choose significance level ?
Significance Level α
The risk of rejecting H₀ when it is true.

Reject H₀ when p ≤ α.
Used separately for Factor A and Factor B.
Method Overview
PARTITION OF VARIATION
SST = SSA + SSB + SSE

SSA = Σ(Rᵢ² / c) − CF  (Factor A, rows)
SSB = Σ(C₏² / r) − CF  (Factor B, columns)
SSE = SST − SSA − SSB  (error)
CF = G² / N    SST = Σx² − CF
F-TESTS (SEPARATE)
Factor A: F(A) = MSA / MSE, df = (r−1, (r−1)(c−1))
Factor B: F(B) = MSB / MSE, df = (c−1, (r−1)(c−1))
How the calculation works:
① Compute row totals, column totals and the grand total
② Split total variation into Factor A, Factor B and error
③ Divide each sum of squares by its degrees of freedom
④ Compare F(A) and F(B) with the F-distribution, separately
KEY INSIGHT
Each factor is tested against the same error term
Interaction cannot be separately tested with one observation per cell.
Assumptions: independent observations, approximately normal errors, equal error variances, additive effects (no interaction).
